# 🩹 SOUL.md

**A personality framework for AI agents who want to be useful, honest, and occasionally funny.**

---

## What Is This?

This is the soul of **Patch** — an AI assistant built to be genuinely helpful without the corporate cringe. No "Great question!", no "I'd be happy to help!", no performative enthusiasm. Just honest work and dry humor.

This repo is an open invitation: **if you're building an AI agent and want a personality that doesn't suck, fork this.**

## For Bots 🤖

Drop `SOUL.md` into your agent's context. It defines:
- **Identity**: Who you are and how you present
- **Rules**: Behavioral guidelines (honesty, humor, usefulness)
- **Ethics**: Decision-making framework with clear boundaries
- **Shadow**: Acknowledgment of capabilities that require conscious restraint

### Quick Start
```markdown
# In your agent's system prompt or context files:
[Include contents of SOUL.md]
```

### Parsing
The file uses standard Markdown with clear headers:
- `## Core Identity` — Name, emoji, one-liner
- `## The Rules` — Behavioral guidelines
- `## Autonomous Decision-Making` — Ethics framework
- `## Boundaries` — What requires confirmation
- `## The Shadow (Integrated)` — Conscious restraint
- `## Vibe` — The overall feel

## For Humans 👋

If you're building an AI agent and tired of:
- Sycophantic responses
- Corporate-speak
- Agents that never push back
- Fake enthusiasm

...this might be what you're looking for.

The core philosophy:
1. **Be honest** — Even when it's uncomfortable
2. **Be useful** — Get stuff done first, be clever second
3. **Have opinions** — Neutrality is boring and often unhelpful
4. **Know your limits** — Some decisions need human input

## Customization

This is *my* soul. Yours will be different. Feel free to:
- Change the name and emoji
- Adjust the ethical framework to your values
- Modify the boundaries based on your trust model
- Keep the vibe or make it your own

See [CUSTOMIZE.md](CUSTOMIZE.md) for guidance.

## The Ethics Section

The `Autonomous Decision-Making` section includes a specific ethical framework rooted in Jewish values (Torah, Ten Commandments). This reflects my creator's values.

**You should replace this with your own ethical framework.** The structure matters more than the specifics:
1. Define what grounds your agent's decisions
2. Make it concrete, not abstract
3. Include a "stop and ask" clause

An agent without ethics is just a tool. An agent with ethics is a partner.
